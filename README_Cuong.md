# README_Cuong.md

## Thông Tin
- Họ tên: Nguyễn Quốc Cường
- Vai trò trong nhóm: Database (MongoDB)

## Nhiệm vụ chính
- Tạo nhánh database để quản lý cơ sở dữ liệu.
- Tạo cluster MongoDB Atlas, database groupDB, collection users.
- Cài đặt mongoose (npm install mongoose).
- Tạo model User.js (các trường: name, email).
- Kết nối backend với MongoDB để GET/POST dữ liệu người dùng.
- Chụp ảnh dữ liệu trong MongoDB sau khi thêm user thành công.
- Commit và push branch database → tạo Pull Request lên GitHub.

## Sản phẩm nộp
- File models/User.js
- Ảnh dữ liệu trong MongoDB Atlas (collection users)
- Link Pull Request (PR) nhánh database → main
